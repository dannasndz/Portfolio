# 🌸 Nanna’s Portfolio

Bienvenida/o a mi portafolio personal 👋  
Soy **Danna Sandez**, estudiante de **Ingeniería en Software y Tecnologías Emergentes** en la UABC, apasionada por el desarrollo frontend, la experiencia de usuario y la creación de interfaces modernas, limpias y funcionales.

Este sitio web es una recopilación de mis proyectos, habilidades, certificaciones y experiencia profesional, construido completamente por mí utilizando tecnologías actuales del ecosistema web.

---

## ✨ Tecnologías utilizadas

Este portafolio está construido con:

- **Next.js 14** – Framework React moderno
- **React** – Librerías de componentes
- **Tailwind CSS** – Estilos con utilidad
- **Vercel** – Hosting y CI/CD
